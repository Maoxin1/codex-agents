# 评估方案导航

先看[当前验证状态](../verification-status.md)，再选择与本次问题相符的方案。此目录是验收材料，不表示已经完成评估，也不授权付费模型调用。

| 目的 | 方案 | 执行方式 |
|---|---|---|
| 比较两个入口与普通对话 | [单轮对照方案](../evaluation-plan.md) | tests/run_coding_eval.py；授权后运行，一题一对，记录配置覆盖路径 |
| 验证创业任务的实际增益 | [创业试用方案](startup-pilot.md) | 按相同输入和环境对照，并收集真实使用反馈 |
| 保存一轮创业试用证据 | [空白记录](startup-record-template.md) | 复制到仓库外填写，避免提交个人材料 |
| 检查分流、证据、约束变化和学习迁移 | [任务路由验收](task-routing.md) | 单轮按案例评阅；多轮必须按实际回复逐轮推进 |

离线脚本只验证结构与记录流程，见[测试说明](../../tests/README.md)。词法匹配不能代替语义评审，旧实验不能证明新版本有效；无增益与失败也应记录。
