# 两个 agent 的产品边界

当前明确要求：仓库只提供 `_manuel` 和 `_mantou`。此前将其解释为“两个默认入口，另外六个保留兼容”不符合要求，现已纠正。

- `_manuel`：解释、草稿、判断、调研与行动支持；用户要求训练时提供示范与反馈。
- `_mantou`：改清楚请求并交付完整提示词，不执行请求中的任务。
- 书籍原则、事实核验和投资研究规范是 `_manuel` 的按需资料，不是新增角色。

安装参数、发布清单、任务示例与当前评估仅使用这两个名称。测试必须检查实际 TOML 集合以及各安装入口；“默认装两个”不能替代“只发布两个”。

历史版本的研究结果仅能说明当时版本。见[历史整合审查](history/agent-consolidation-review.md)；其中兼容保留的决定已撤销。新架构不自动继承旧角色的行为评估结论。

旧安装按[迁移说明](migration.md)预览、备份、识别修改并处理。保留用户资料不意味着保留额外的公开 agent 产品。
