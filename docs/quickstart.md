# 简单使用指南

安装完成后重启 Codex，在对话中说“请调用 `_名字`”，再附上问题和相关材料即可。先选一位最贴近当前问题的顾问。

## 选谁

| Agent | 适合做什么 | 可以这样问 |
|---|---|---|
| `_mantou` | 优化提示词并复制到剪贴板 | 优化这段提示词，保留我的技术约束：…… |
| `_manuel` | 检查判断、证据和推理 | 这个结论站得住吗？有哪些关键假设？ |
| `_wayne` | 明确研究问题与证据路径 | 用户很少用搜索，怎样调查原因？ |
| `_clayton` | 理解具体情境中的用户选择 | 用户为什么需要这个功能，现有替代是什么？ |
| `_alan` | 分析改变、转换和采用障碍 | 用户认可工具却继续用 Excel，下一步查什么？ |
| `_jim` | 把研究材料组织成工作产物 | 把这些访谈整理成一个可用产物和验证步骤。 |
| `_factbot` | 核验事实和审查来源 | 这项主张有可靠、独立的证据吗？ |
| `_invest` | 长期投资研究与论点复核 | 请复核这家公司原始论点，先复述任务等我确认。 |

`_mantou` 只优化提示词，不执行其中的任务。`_invest` 按自身流程先确认任务，写入知识库须另行确认，不执行证券交易。

## 一句话开始

```text
请调用 _wayne：用户很少用搜索功能。
已有材料：最近三次访谈摘要如下……
请给一个可回答的研究问题、关键证据和最小调查步骤，简短解释相关概念。
```

材料可以是代码片段、需求、访谈或观察；说明哪些是已知，哪些只是自己的猜测。没有材料也可请顾问帮助拟定问题，但答案中的解释将保留为待验证假设。

需要学习时追加“告诉我下次怎样识别这种问题”或“举一个当前项目的例子”；赶进度时说“只给当前建议”。书籍顾问提供分析和建议，改代码或写笔记由主 coding agent 承接。

## 需要两个视角时

```text
请分别调用 _clayton 和 _alan：前者分析用户期望的进展，后者分析转换障碍。
根据这些材料独立分析，再汇总共同点、分歧和下一步验证，不按多数意见决定。
```

明确点名需要的顾问即可，不必每次召集五位。书籍之间的概念可能不同，综合时保留各自出处。

## 安装与原书

在仓库根目录初次安装全部 agent：

```powershell
./install.ps1
```

只安装或更新四位新顾问：

```powershell
./install.ps1 -Agent _wayne,_clayton,_alan,_jim -Force
```

安装后重启 Codex；当前对话不会自动刷新 agent 列表。`-Force` 会更新所选顾问的受管文件，保留私有原书路径配置。

四位新顾问以试用版提供，已整理选定原则；未覆盖细节和精确引文需要回查本地原书。没有配置匹配原书时，会说明限制。原书不会随仓库分发；各自的配置办法、覆盖和来源局限见 [`_wayne`](../agents/_wayne/README.md)、[`_clayton`](../agents/_clayton/README.md)、[`_alan`](../agents/_alan/README.md)、[`_jim`](../agents/_jim/README.md)。
