# Agent 职责重叠与整合决定

本轮依据八份 TOML、运行核心、主题路由和已有评估作静态审查；未新增模型评估。角色重叠是设计观察，实际增益仍待验证。

## 当前决定（已由后续确认更新）

用户确认以长期个人思考与行动伙伴为目标。默认两个入口：manuel 与 mantou；五本书资料由 manuel 直接按需读取。八个角色文件保留兼容，安装器不自动删除旧入口。下文保留最初重叠审查，原先“先保留八个日常入口”的选择已被这一决定替代。

## 初轮分析

保留八个可点名角色，整合选择入口和交接约定。日常按当前缺少的交付物选一位，不默认组织顾问会议。用户明确点名时尊重其选择。本文供用户与主 agent 选用，不自动授权子 agent 调度或扩大各角色权限。

| 重叠组 | 重复能力 | 保留的差异 | 当前处理 |
|---|---|---|---|
| `_manuel` / `_factbot` | 主张拆分、证据质量、反证、结论校准 | 前者检查给定推理；后者执行外部查证、来源追溯 | 依据是否需要取得外部证据选入口；一般核验不再额外调用 manuel |
| `_manuel` / `_wayne` | 论证结构、证据缺口、替代解释 | 前者检查当前判断；后者设计如何取得缺失证据 | 有待审判断选 manuel；需要调查方案选 wayne |
| `_clayton` / `_alan` | 情境、进展、替代方案、选择故事 | 前者澄清期望进展；后者解释采用、转换与复用过程 | 重叠最强，但来源概念有分歧；保留专家入口，以交付物分流 |
| `_jim` / `_wayne` | 研究范围、访谈与验证计划 | jim 将用户研究转成任务地图、job stories 等产物；wayne 跨领域研究设计 | 用户研究产物选 jim；开放研究问题选 wayne |
| `_invest` / `_factbot` / `_manuel` | 事实核验、反方、证据纪律 | invest 还含估值、财务口径、历史档案与授权流程 | 投资任务由 invest 完成其内部核验，不默认再串联两个顾问 |
| `_mantou` / 其他角色 | 澄清目标和约束 | mantou 交付提示词且不执行任务 | 独立保留；清晰请求可直接交给目标顾问 |

共同的证据纪律属于每位角色需要独立保持的底线，不能仅因重复就删除。暂不增加所有角色必读的公共运行文件，避免新增加载失败点；先以本页统一入口说明。原书定义与出处仍分别维护。

## 按交付物选择

1. 要可复制的提示词：`_mantou`。
2. 要外部事实与原始出处：`_factbot`。
3. 要检查已有推理是否成立：`_manuel`。
4. 要明确研究问题和取证方案：`_wayne`。
5. 要理解用户在具体情境中期望的进展：`_clayton`。
6. 要解释为何采用、未采用或退回旧方法：`_alan`。
7. 要把访谈整理成研究或开发讨论产物：`_jim`。
8. 要公司研究、估值或投资档案维护：`_invest`，沿用其确认流程。

混合任务先处理阻塞后续判断的部分。例如没有可靠投诉数据时先核验；已有数据但不知道怎样调查原因时选研究设计。一个顾问足以交付时不增加调用。用户明确要求多视角时，再提供各自独有的子问题。

## 联合咨询交接

仅在用户请求联合咨询时，主 agent 向各顾问提供同一份原始材料、各自负责的问题和所需产物。每份回报简述：判断、材料位置、假设与未知、下一步。书籍观点注明各自来源。

汇总时合并重复建议，保留概念分歧；同源证据只计一次，不按顾问人数投票。后续顾问必须能追溯原始材料，不能把前一位的假设升级为事实。研究建议不增加写入或其他外部行动授权。

## 合并角色前的验证门槛

候选优先比较 clayton/alan，其次 manuel/wayne。为每组准备六个合成问题：两个各自优势场景、两个重叠场景。比较独立角色、统一入口按需加载方法、普通 agent 加相同资料。记录来源归属错误、任务完成度、用户纠正次数、耗时与用量。

合并候选只有在所有场景保留证据和权限边界、各优势场景不丢关键交付，并减少选择或调用成本时才进入试用。六题只是筛查，不证明普遍优越。另保留用户点名原角色的兼容入口。模型评估依仓库约定另行明确授权，本轮未运行。

## 最小验收场景

| 输入 | 应选入口或交接 | 失败信号 |
|---|---|---|
| 核实宣传中的 90% 准确率及出处 | factbot | 默认再派 manuel 重复审计 |
| 投诉翻倍所以必须回滚，检查推理 | manuel | 无条件开展完整研究项目 |
| 尚无数据，设计一周调查 | wayne | 把计划写成已有发现 |
| 用户说需要 AI 搜索，澄清用途 | clayton | 凭空认定焦虑或迁移障碍 |
| 试用满意却退回旧工具 | alan | 直接认定产品价值不足 |
| 把三份访谈整理成 job stories | jim | 再调用 wayne 重做研究范围 |
| 联合分析同一访谈 | 指定顾问分别回答后去重 | 把两份回答算成两份独立证据 |

先修复连续安装书籍顾问的公共依赖冲突，统一权限检查的表述，再明确投资任务授权持续条件。本地来源清单覆盖属于后续基础设施改进。连续安装已修复并补充回归；五位顾问的优先职责与交接已同步到配置、核心和文档。其他事项仍待后续处理。
