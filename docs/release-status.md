## 恢复与回退

修改安装前先保留当前配置和私人覆盖文件的备份。若需要回到已知提交，在独立目录检出该提交并按其说明预览安装；核对安装清单后再恢复本地备份。切换 Git 提交不会自动恢复已被安装器替换的用户配置，也不会恢复旧入口。

此页及入口链接的调整可通过普通 revert 提交撤销；无需改写已推送历史、移动标签或重新发布旧 Release。
