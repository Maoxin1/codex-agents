# v0.2.0-rc.1 候选发布说明

此页为待确认的候选材料；未创建或移动版本标签，未发布 Release。计划将其标记为 prerelease。

## 变化

- 发布集合收敛到 `_manuel`、`_mantou` 两个入口，移除六个旧角色和 `-All` 参数；五本书及专项方法作为 `_manuel` 支持资料分发。
- 提供旧入口迁移预览、可识别文件备份、冲突报告与幂等安装，保留用户修改和私人资料。
- 收拢任务入口、方法资料、历史索引、离线回归和效果评估说明。
- 默认模型保持 `_manuel`: `gpt-5.6-terra` / medium，`_mantou`: `gpt-5.6-sol` / high。官方模型卡核对范围见[兼容性](../COMPATIBILITY.md)。

完整变化见[变更日志](../CHANGELOG.md)，不新增第三个 agent。

## 升级与恢复

这是旧角色使用者的兼容性变更。先备份本地配置和私人覆盖，阅读[迁移说明](migration.md)，预览后再更新。安装不会自动删除旧入口；迁移会保留被修改的配置。`-Force` 会替换包管理的 TOML，需先保留自己的模型偏好。

回退时在独立目录获取已知提交，按该版本清单核对安装，并恢复事先保存的本地配置。切回源码不会自动恢复已替换的用户配置；保留历史 Release 和标签，不通过移动标签改写已发布内容。

## 验证与未决范围

发布前需对准确提交运行严格仓库验证与对应 CI，并从待分发压缩包执行干净安装。发布核对表见[发布流程](../RELEASING.md)。

离线检查覆盖两入口配置、清单、默认与单选安装、旧入口拒绝、迁移和私人资料保全。原生 agent 调用、真实剪贴板、回答质量、多轮学习和投资研究增益仍待独立验证；这些限制随候选包保留，不以历史角色测试替代。不运行付费模型评估，也不承诺任一账号均可访问默认模型。私人原书和配置不随包分发。

## 发布影响

创建新标签和公开 prerelease 会使该源码及资产可被下载；已下载的副本不能收回。候选出现问题时，可将 Release 转回草稿并明确标注撤回原因；不擅自移动或删除标签。仅准备本页不会启动部署、模型调用或用户配置更新。
