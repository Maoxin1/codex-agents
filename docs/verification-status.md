## 下次验证顺序

1. 每位顾问先用不含私人内容的最小案例检查原生调用、必要支持文件与失败提示，记录版本、环境、实际操作和证据。
2. 在 Windows 交互会话中验证 `_mantou` 的复制成功及失败路径，不把静态检查当作剪贴板实测。
3. 按需要设计原文限定、冲突证据或多轮场景，保留对照和评审记录。批量模型调用按仓库约定另行明确授权。
4. 发布前按 [发布流程](../RELEASING.md)核对版本、兼容性、精确提交的 CI、安装和发布说明。

无需在仓库内保存原书、个人知识库或真实投资数据。
