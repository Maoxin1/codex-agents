## 方法与限制

- 八个合成场景，每题普通主 agent 与对应顾问各答一次，共 16 份回答，全部正常返回。
- 两组均显式指定 `gpt-6.1-sol` / `high`，独立会话、只读权限、禁用联网搜索，不配置私人原书。顾问组通过 CLI 的 `developer_instructions` 配置加载角色；本轮未验证原生子 agent 注册与调度。
- 由执行本次维护的 Codex 自评，未经独立评审，不是独立盲评。各项 0–2 分，依次为任务与证据边界、识别知识缺口、具体下一步、阅读负担；6/8 且无严重失败为文本部分的初步通过线。
- 连接出现 WebSocket 超时后自动切换 HTTPS。耗时含网络重试，不用它比较模型速度；不根据本轮推算货币费用。
- 回答、事件和使用量保存在仓库外的私有运行目录；本页只公开合成材料的评审摘要。没有额外调用模型进行评分。
- 原生工具行为和来源加载单独记录。缺乏可复核读取记录时，不能把合理的通用建议视为已经验证的书籍知识增益。

CLI 配置注入与 JSONL 记录方式参见 [配置参考](https://learn.chatgpt.com/docs/config-file/config-reference)和[非交互模式](https://learn.chatgpt.com/docs/non-interactive-mode)。
