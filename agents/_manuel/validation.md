## 离线检查

从仓库根目录运行：

```powershell
./tests/validate_repository.ps1
```

单包检查可运行 `py -3 agents/_manuel/tests/validate_manuel.py`；环境已有 python 命令时可用 python 替代。只有提供匹配的 MANUEL_SOURCE_PDF 并安装 PyMuPDF，才会复核原 PDF 身份与锚点；未提供时报告跳过，不把历史核验当作本次运行。

## 行为验收

[任务分流与多轮协议](../../docs/evaluation/task-routing.md)检验是否直接完成简单任务、随新证据修改方案，以及是否基于用户真实回答提供反馈。[创业对照](../../docs/evaluation/startup-pilot.md)检验具体任务增益。完整流程索引见[测试说明](../../tests/README.md)。
