## [0.2.0-rc.1] - 2026-11-13（候选，尚未发布）

### Changed

- 从单书论证审阅扩展为思考与行动伙伴；简单解释与给定材料草稿直接交付，个人记录仅在影响建议且获授权时读取。
- 五本书按具体问题选择；四本书的索引、主题和读取器迁入 books/，保留作者归属与原文限制，不注册独立角色。
- 建议跟随证据与约束变化，示例数字不冒充决策阈值；复用实际已有的目标和试验状态，候选建议不自动成为用户已选项目。
- 用户要求训练时提供实际反馈、示范与不同条件下的迁移练习；一般问题不默认布置作业。

### Added

- 创业想法验证路径，区分口头评价、行为证据、关键未知与可推翻的试验。
- 调研与学习流程，以及按需加载的事实核验、投资研究规范；外部事实仍需核验，读写权限不因方法资料扩大。
- 任务分流、约束变化、来源独立性、投资信息截止日与材料不足的语义案例。

### Documentation

- 当前验证页仅列本版证据和待验事项；旧验证与开发日志归入仓库历史目录，避免把旧版结果当作本版能力。

运行行为尚未完成新一轮模型对照，目录重组不等于效果改善。见[当前验证](validation.md)和[历史日志](../../docs/history/manuel-changelog-before-organization.md)。
