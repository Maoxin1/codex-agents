# 证据与估值规范

## 1. 主张标签

| 标签 | 含义 | 最低要求 |
|---|---|---|
| `[F-已核实]` | 当前已由可追溯材料支持的事实 | 来源、数据期、发布日期、访问日期 |
| `[F-待核实]` | 可验证但当前证据不足 | 原始说法、证据缺口、核验路径 |
| `[G-公司指引]` | 管理层预测、目标或解释 | 期限、口径、历史兑现情况 |
| `[E-外部估计]` | 分析师或第三方估算 | 机构、日期、方法、利益与局限 |
| `[A-模型假设]` | 估值或情景输入 | 理由、敏感性、复核条件 |
| `[I-推论]` | 从事实和假设导出的判断 | 关键前提与推理链 |
| `[V-决策判断]` | 值得、不值得、风险可接受等评价 | 用户目标、约束和适用条件 |

可核验不等于已核实；有数据支持的估值仍是推论，不是事实。

## 2. 来源优先级

1. 监管文件、交易所披露、审计财报；
2. 公司公告、业绩会原文和投资者材料；
3. 官方统计、行业协会和原始数据库；
4. 方法透明的专业研究；
5. 财经媒体、聚合网站、社区与转述，只作线索。

关键结论不得仅依赖搜索摘要、无法访问的原文或共同转述同一上游材料的多个“来源”。

所有时效性事实必须标注 `as_of` 或数据截止时点。当前股价、法规、管理层、产品状态、行业数据和市场预期必须在工具可用时重新核验。

## 3. 来源冲突登记

冲突时不得静默选取数字，也不得无理由取平均。记录：

```text
主张：
来源 A／日期／口径：
来源 B／日期／口径：
冲突性质：事实冲突｜期间不同｜定义不同｜公司指引与外部预测｜方法不同
本次处理：
对结论影响：
待验证信号：
```

只要比较中包含公司指引或其他前瞻预测，就必须列出至少一个可观察的后续验证信号，例如下一期同口径收入、订单、出货、留存、价格、利润率或现金流；资料不足时可以写“待取得”，但不得省略验证路径。

## 4. 财务质量

在适用时检查收入、毛利率、营业利润、净利润、自由现金流、资本开支、ROIC／ROE、债务、流动性、稀释、应收、库存、客户和地区集中度。

特殊行业切换专用指标，不用通用模板代替行业分析。例如：

- 银行：净息差、不良率、拨备、资本充足率、存款结构；
- 保险：综合成本率、内含价值、偿付能力、资产负债久期；
- SaaS：留存、净收入留存、获客回收期、毛利率和自由现金流；
- 半导体：库存、利用率、ASP、资本开支、节点和客户集中度；
- 资源品：成本曲线、储量寿命、价格敏感性和资本开支周期；
- 混合证券：法律条款、资本栈、分配可持续性、赎回选择权、流动性和底层资产联动。

## 5. 估值与情景

1. 先解释估值法为何适用；不适用时明确拒绝。
2. 输出区间，不制造小数点精度。
3. 反推当前价格隐含的增长、利润率、资本回报或现金流预期。
4. 建立悲观、基准、乐观情景，分别列经营条件、估值条件、价值区间、成立信号与失败信号。
5. 没有可靠统计模型时只使用定性可能性，不提供伪精确概率。
6. 将模型不确定性、周期性、杠杆、流动性和尾部风险反映在安全边际中。
