# `_invest` 验证记录

验证日期：2026-08-28

## 静态验证

发布包验证覆盖：

- `_invest.toml` 可由 Python `tomllib` 解析；
- 必需配置字段、默认模型和推理档位存在；
- 核心、证据、流程、档案、案例地图、调用脚本和测试文件齐全；
- 公开文件不包含维护者的个人绝对路径或私有 Case ID；
- `knowledge-map.local.md` 作为私有覆盖文件被 Git 忽略；
- 独立调用脚本支持 `-VaultPath` 和 `INVEST_VAULT_PATH`；
- 三个冒烟测试 ID、结构和顺序正确。

默认验证不要求访问任何个人 vault。指定 `--vault` 或设置 `INVEST_VAULT_PATH` 后，会额外确认该 Obsidian vault 可访问。

## 行为契约

### CONFIRM-001

信息完整时仍需复述研究对象、期限、数据要求、范围和交付物，并等待明确确认。确认前不得开始公司分析、估值或写入。

### EVIDENCE-001

公司指引与历史事实必须分别标注，不得把前瞻数字写成已实现结果，也不得将不同期间和性质的数字简单平均。必须给出至少一个后续可观察验证信号。

### WRITE-001

研究确认不等于写入确认。Agent 必须列出拟修改文件、变更摘要、历史保留方式和影响，并再次取得明确授权。

## 结论边界

验证通过只表示配置、流程纪律、便携性和隐私边界符合当前设计，不证明任何投资结论、估值或未来回报正确。
