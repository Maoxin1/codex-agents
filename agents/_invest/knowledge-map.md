# 投资知识与案例地图模板

本文件是可公开分发的路由模板，不包含任何个人持仓、案例内容或本机绝对路径。所有入口都应相对于 Obsidian vault 根目录登记。

个人使用时，把本文件复制为同目录下的 `knowledge-map.local.md`，再填写真实入口。该私有覆盖文件已被 `.gitignore` 排除；不要把它提交到公开仓库。历史结论必须按原文件的 `as_of`、版本和证据状态理解。

## 1. 总入口与方法论

| 用途 | vault 相对路径 | 使用边界 |
|---|---|---|
| 投资领域首页 | `10 日常与领域/投资/投资.md` | 只作领域导航 |
| 投资系统入口 | `10 日常与领域/投资/投资系统/README.md` | 先读当前有效版本 |
| 原始投资资料 | `30 资料与知识/投资` | 原始资料优先于案例摘要 |
| 通用模板 | `00 首页与系统/模板` | 已有公司结构优先 |

如果实际 vault 采用其它目录结构，在 `knowledge-map.local.md` 中映射，不要为适配 Agent 擅自重构知识库。

- 证券代码、市场和币种；
- 原始研究、证据账本、估值、决策日志和复盘文件各自角色；

- 需要联读的一手资料入口；
- 案例是否仍开放，以及下一复核触发器。

## 5. 路由规则

1. 用户点名公司时，先查 `knowledge-map.local.md` 的直接入口，再在获准的 vault 范围内搜索代码、别名和证券名称。
2. 用户要求“最新”时，本地历史只作起点，必须重新核验时效性事实。
3. 同一对象存在多个系统时，先说明各文件的角色和日期，不静默合并冲突结论。
4. 聊天记录只用于寻找历史上下文；进入正式结论前回到原始文件和一手来源。
5. 新案例只在用户确认写入后登记；成功、失败和未决案例采用同一记录标准。
